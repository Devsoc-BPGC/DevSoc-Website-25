# DevSoc artwork: copy-paste prompts

Fourteen images. Each block below is complete on its own. Copy one block, paste, generate, save under the filename above it. Nothing to append.

Order matters if you are doing a few at a time: **1, then 5 to 10.** Those seven carry the site.

Save everything under `public/images/` at the path given. Placeholders are already committed, so the site works while you generate and each file just replaces one.
