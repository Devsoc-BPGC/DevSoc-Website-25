# DevSoc artwork: copy-paste prompts

Fourteen images. Each block is complete on its own. Copy one, paste, generate, save at the filename above it, at the size given.

Order if you are doing a few at a time: **1, then 5 to 10.** Those seven carry the site.

Placeholders are already committed, so nothing breaks while you work through these.

---

## The idea

**The lit facade.** One building seen through one night. A flat, almost architectural grid of windows: most dark, some lit warm amber, each lit window a room where somebody is building something. The hero has a handful lit. DevFest has every window lit. Dawn has them going out, with one door open.

It comes straight from the line the site opens on: the campus sleeps, six rooms stay lit. It is DevSoc's own image and nothing else's.

**Style:** flat vector illustration, bold geometric shapes, limited palette, subtle grain. Almost a screen print of an elevation drawing. No photorealism, no 3D rendering, no text.

**Palette:** deep indigo, near-black, bone white, patina teal, warm amber, brass.

**Two hard rules.** No night skies, no auroras, no star fields, no moons, no palm trees, no flowers, no meadows. And nothing may look like a photograph or a render. If a result is beautiful but breaks either rule, it is wrong.
