# DevSoc artwork: copy-paste prompts

Flat illustration, not photographs and not renders. Each block below is complete on its own. Copy one, paste, generate, save at the filename above it.

Order if you are doing a few at a time: **1, then 5 to 10.** Those seven carry the site.

Placeholders are already committed, so nothing breaks while you work through these.

---

## The style, in one line

**Flat vector illustration and poster art.** Bold flat colour fields, simple shapes, limited palette, a little grain. No photorealism, no 3D renders, no complicated machinery, no text anywhere in the image.

Two kinds of image here:

- **Scenes** (1 to 4, 11, 12): flat illustrated skies and horizons. Gradient ground, star speckle, simple silhouettes.
- **Posters** (5 to 10): one flat colour field with a single simple object sitting on it. A phone, a controller, a browser window. The object is the whole idea.

The palette across everything: deep indigo, near-black, bone white, patina teal, warm amber, brass.

The flywheel itself is not generated. It is drawn in code as SVG so it can turn as you scroll and light up the vertical you are on. These six posters are what ride on it.

If a result looks like a photograph or a 3D render, it is wrong even if it is beautiful. Flat shapes, flat colour, no depth.
